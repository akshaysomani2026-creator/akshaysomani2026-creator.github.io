What I learned building a plant disease detector

When I started the leaf disease project, I thought the hard part would be the neural network. It turned out that the network was only half of the story. The other half was the data.

A convolutional neural network learns by looking at many labelled images and picking up the patterns that separate one class from another. We trained ours on the PlantVillage dataset, which has 54,305 leaf images across 38 classes. Seeing a model reach about 91% validation accuracy was exciting, but it also taught me to read that number carefully. It tells me how well the model does on images it was not trained on, from the same collection. It does not promise the same result on a photo taken in a real field, with different light and a messier background.

That lesson is why I am drawn to data engineering. A model can only be as useful as the data that feeds it, so collecting, storing and cleaning data deserves as much care as the model itself. The project was also part of a team effort on smart irrigation and plant disease detection, and it showed me how one piece of work fits into a bigger system.

Next, I want to keep building small projects like this one, and learn how to prepare data properly so that the results I report are ones I can trust.
